Skin Cleanser Store

1. Project Introduction

Skin Cleanser Store is a simple and responsive skincare e-commerce
website.
It allows users to view skincare products, check product details, and
use the shopping and checkout pages.

2. Objectives

Create a clean and responsive skincare website.

Display skincare products in an attractive way.

Provide product details and shopping pages.

Make the website easy to use on desktop and mobile devices.

Add basic JavaScript interactivity.

Deploy the website online.

4. Website Pages

Home Page

The home page introduces the Skin Cleanser Store and displays featured
products and website sections.

Shop Page

The shop page displays skincare products for users to browse.

Product Detail Page

This page shows detailed information about a selected product.

About Page

This page provides information about the store.

Contact Page

This page provides contact information and a contact form.

Checkout Page

This page is used to complete the shopping process.
